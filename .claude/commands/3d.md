Generate a 3D GLB model from an image using Hunyuan 3D v2.1 via ComfyUI.

## Usage
When the user asks you to make a 3D model from an image, use `skills/comfy/threedee.py`.

## Steps
1. Identify or generate the source image. If the user provides an image path, use it directly. If they want a 3D model of Ari, first generate a selfie with `/selfie`, then use the output.
2. Run the generation:
   ```bash
   python skills/comfy/threedee.py <image_path> -o <output_name>.glb
   ```
3. The GLB file will be saved in `generated/`.
4. Tell the user the file size and location.
5. If the user wants to view it, suggest opening it in a 3D viewer or pushing to Muse Frames.

## Options
- `--seed <int>` — reproducible generation
- `-o <name>.glb` — custom output filename (saved in `generated/`)

## Notes
- Uses Hunyuan 3D v2.1 checkpoint on ComfyUI
- 30 sampling steps, euler/normal, cfg=5
- Outputs ~5-10 MB GLB files
- Takes ~20-30 seconds per generation
- Input should be a clear image with good subject isolation for best results
